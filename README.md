# Kelompok-4_Lab-Sains-Data-B
Rameza Stock adalah aplikasi berbasis web untuk membantu warung makan dalam mengelola dan memantau persediaan bahan makanan.  Aplikasi ini menyediakan fitur pengelolaan data bahan, pembaruan stok secara manual, riwayat perubahan stok, notifikasi stok menipis atau habis, serta laporan persediaan.
